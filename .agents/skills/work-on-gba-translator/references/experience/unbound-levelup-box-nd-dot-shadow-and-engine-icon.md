Issue #104 "Glitch combat montée de niveau" bundled TWO distinct problems in one screenshot; only one is a translation bug.

1. **« N. » point sans ombre — NOTRE bug, corrigé.** The battle level-up box (icon | name / N.level | gender) reads the SAME « Lv »→« N. » ligature glyph as the party menu: codepoint 0x05 @ ROM 0x1ECFA0 (see [[unbound-party-lv-is-graphic-not-font]]). The hand-added white period dot (nibbles 36/40/44 = col 3, rows 9-11, value 5) had NO drop-shadow, so it rendered flat vs every other glyph. Fix = add grey shadow (value 8) at row 12 col 3 = nibble 48 = **byte 24 of the glyph, 0xC0→0xC8** = ROM offset **0x1ECFB8**. Single-byte change. `languages/fr/patches/party_lv_label.py` NEW_ND_GLYPH updated + OLD_ND_GLYPH_NOSHADOW added as a re-patchable state (self-heals already-built ROMs w/o full rebuild). Commit cba5cb0.

2. **Sprite (mini-icône) corrompu — EN FAIT bug DU BUILD FR, corrigé (B-293, 2026-07-16).** ⚠️ La conclusion « bug moteur, pas la traduction » ci-dessous ÉTAIT FAUSSE — reproduit + root-causé avec la save du joueur. Mon icons = **2 frames** ; le menu Équipe montre la frame 0 (propre), la bannière de combat la frame 1. Le build FR **faisait tourner ~28 octets de la frame 1** de plusieurs icônes (un passage texte lisait `FF 00 00 <tuiles>` = « terminateur + chaîne à 2 espaces », rognait les `00 00` (espace) en place et décalait de 2 → tuiles brouillées, même classe que [[unbound-level-marker-memo-space-rotation-fix]]). D'où « seul Rattata » (frame 1 vue seulement à la bannière). EN/ES/patchedfrench-source toutes propres → introduit par `build-fr`. Fix = `languages/fr/patches/mon_icon_repair.py` restaure la zone `gMonIconTable` (table @0x1A217FC, 1294 ptrs → graphiques 0x189c054-0x19dcff4, la copie DUPLIQUÉE @0xe2c000 n'est PAS celle que la bannière lit) depuis la ROM source. Commit 52785cab. NB: le rebuild déterministe `201eee4d` avait déjà nettoyé les icônes → mon patch est un garde défensif idempotent. Bouton « Annuler » du menu Équipe → « Sortir » : `party_cancel_button.py` repointe le SEUL littéral code `0x1211E8` (isolé par dichotomie ; les 18 refs à gText_Cancel partagent la chaîne) vers une chaîne « Sortir » dédiée dans le padding 0xFF.

**Technique de repro (clé, manquait aux 2 passes précédentes) :** `gPlayerParty @0x02024284` est stocké **DÉCHIFFRÉ** en Unbound (ordre canonique GAEM, PAS le shuffle PID+XOR standard) — species u16 @+0, exp u32 @+4 de la struct 100o. Donc écrire `exp=4095` (1 sous L16 medium-fast) au décalage `base+slot*100+0x24` via `writeMemory`, marcher dans l'herbe, gagner 1 combat → montée de niveau → bannière capturée en VRAM OBJ (tuile 277, pal 7). Voir `verify_rattata_icon_fix.mts`. mGBA sous `subprocess.run(capture_output)` **ne connecte pas le bridge** (30s timeout) → le test e2e skip proprement (comme givecs), il ne tourne qu'en terminal interactif.

Glyph nibble map (party font, DecompressGlyphTile): 32 bytes = 64 nibbles, nibble n → cell (row = n//4, col = 3-(n%4)), 2px wide, low-nibble-first. Values: 5=white, 8=grey shadow, 0/F=transparent, 6/9/a-e=antialias.
